# Shaswat Shukla

Personal portfolio at https://shaswatshukla.github.io/.

SIGNAL: an original futuristic portfolio with a locally rendered interactive particle constellation, luminous typography and real project links. A searchable project launcher opens with Explore or Ctrl/Command K. The project gallery, books and career history use compact, responsive layouts. All content is static HTML; filtering, previews and search are progressive enhancements in app.js and future.js. Dark is the default theme, with a separate locally stored theme preference. Motion pauses offscreen and in background tabs, honors reduced-motion preferences and has a manual pause control. No third-party runtime scripts or analytics.

All seven projects and both books retain their original links and factual descriptions. Full descriptions and supporting facts are available in native details disclosures. Local fonts and images avoid runtime third-party dependencies.
