# Shaswat Shukla

Personal portfolio at https://shaswatshukla.github.io/.

An original woodland portfolio inspired by Overlake's evergreen palette, warm paper surfaces, editorial serif headings and flowing section edges. An original SVG forest surrounds the interactive project workbench. The project gallery, books and career history use compact, responsive layouts. All content is static HTML; filtering and preview controls are progressive enhancements in app.js. Light is the default theme, with a separate locally stored theme preference. The interface respects reduced motion and supports keyboard navigation.

All seven projects and both books retain their original links and factual descriptions. Full descriptions and supporting facts are available in native details disclosures. Local fonts and images avoid runtime third-party dependencies.
